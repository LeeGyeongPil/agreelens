# Changelog

All notable changes to this project are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-11-13

### Fixed
- The single-label judge warning ("kappa is 0") no longer appears when kappa is NA because both sides used the same single label.

## [0.1.0] - 2026-11-11

### Added
- Load a CSV, TSV or JSONL file (nested JSONL keys become dot paths) or one of two bundled practice samples (synthetic data).
- Column mapping with guessed defaults, label cleaning (trim, case, missing values), label merge / leave-out table, explicit order for ordinal text labels, majority or single-column reference.
- Statistics in a React-free core: percent agreement, Cohen's kappa (unweighted, linear and quadratic weighted) with seeded bootstrap 95% CI, MCC, Krippendorff's alpha (humans only and with the judge), kappa per human, confusion matrix, per-label precision and recall, lenient / strict direction, McNemar test.
- Warnings for the kappa paradox, a judge that uses one label, small samples and left-out rows; undefined statistics show NA with a reason instead of 0.
- Confusion-matrix cells open a disagreement table with expandable text, notes saved in the browser, and a CSV export that includes the notes.
- HTML and JSON report export in the current language.
- English and Korean interface with a language menu (saved in local storage, detected on the first visit only; `?lang=en|ko`).
- Address options `?sample`, `?view`, `?cell`, `?lang` for shareable views.
- Single-file build (`dist/index.html`) with a Content-Security-Policy that blocks all network requests; `scripts/check-dist.mjs` and `scripts/smoke-dist.mjs` verify it.
- Reference values from scikit-learn, krippendorff and statsmodels (`tests/fixtures/ref.json`, regenerated by `scripts/make_ref.py`).

### Known issues
- For an unclosed CSV quote the reported data row is one too high.
- When both sides use the same single label, kappa is NA but the "kappa is 0" warning for a single-label judge is still shown.
